### 3. Story 12.1 yielded a new ratified project norm: `feedback_monkeypatch_decorator_chain_walk`

Test contamination bug during Story 12.1 dev: combined `tests/unit/conventions/ tests/unit/judge/` runs failed 13 of 18 judge tests with `LiteLLMAdapter.chat requires model ...`. Root cause: `tests/unit/conventions/_walk.py:load_module_from_path` calls `importlib.util.spec_from_file_location` and OVERWRITES `sys.modules["AgentEval.judge.library"]`. The test file's module-level `JudgeLibrary` import (captured at test collection time) bound to the OLD module; a fresh `from AgentEval.judge.library import JudgeLibrary` inside the patch helper retrieved the NEW class from the overwritten `sys.modules` entry; patching the new module's `get_adapter` did NOT affect the old function's lookup namespace.

**Fix (3-step pattern):** (1) use the module-level `JudgeLibrary` reference (don't re-import inside fixtures); (2) walk the `@tier(2)` + `@guarded_fanout` decorator chain via `__wrapped__` to reach the innermost function whose `__globals__` IS `library.py`'s module dict; (3) `monkeypatch.setitem(innermost.__globals__, "get_adapter", lambda name: _FakeAdapter)` targets the real lookup namespace regardless of `sys.modules` state.

**Memorialized as** `~/.claude/projects/-home-many-workspace-robotframework-agenteval/memory/feedback_monkeypatch_decorator_chain_walk.md` with full diagnosis + 3-step pattern + Why/How. Indexed in `MEMORY.md`. **Load-bearing for all future tests against `@tier+@guarded_fanout`-decorated keyword methods** — the Story 12.2 `test_library_calibrate.py` + Story 12.3 `test_devon_three_tier_complete.py` both adopted the pattern without re-discovering the bug.

### 2. Libdoc keyword-name display bug shipped through entire Epic 12 dev cycle — caught at post-merge README hygiene, not at code review

Story 12.2 shipped `@keyword(name="Judge.Calibrate")` — a single-word post-dot namespace-prefixed keyword. None of the 6 reviewer invocations (sonnet + opus × 3 stories) flagged this. **Honest framing per `feedback_honest_framing`:** the rename `Judge.Calibrate` → `Judge.Calibrate Rubric` was applied IN-EPIC at commit `77aa820` before push to origin/main — so no external user saw the broken name.
