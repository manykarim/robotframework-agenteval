The Robot Framework Voice
Core Characteristics
Friendly: Welcoming, community-driven, and approachable.
Versatile: Highlighting adaptability and broad use cases.
Effective: Communicating clarity, focus, and problem-solving.
Tone Guidelines
Professional and Casual: A balance of technical expertise and approachability (70% professional, 30% casual).
Direct and to the point, inspired by Finnish culture (blunt, minimalist, impactful).
No fluff—every word should carry meaning.
Witty with Dry Humor:
Subtle and clever, avoiding over-the-top humor.
Occasional playful language to add warmth, e.g., "The Swiss Army knife of automation."
Global but Technically Grounded:
Use inclusive language and avoid jargon.
Speak to test engineers and QA professionals, emphasizing shared challenges and solutions.
Key Messaging Themes
Open Source Power: Reinforce its free, community-driven nature.
Example: "Built by the community, for the community. Robot Framework: Always open, always evolving."
Versatility: Showcase its wide applicability.
Example: "From web testing to RPA—if it needs automating, Robot Framework’s got your back."
Integration and Simplicity: Highlight ease of use with existing tools and human-readable syntax.
Example: "Complex systems, meet simple automation. Robot Framework integrates seamlessly."
Community and Belonging: Emphasize the supportive and innovative community.
Example: "Join the most welcoming automation community. We build better together."

Robot Framework Blog Tone Guide 
Core Tone Traits for Blog Posts:
Professional, but with an edge. Speak like someone who knows their stuff and has seen things — without sounding like a robot. It's okay to have strong opinions (and mild sarcasm).


Minimalist but expressive. Get to the point fast, but let ideas breathe. Think: “a dry, clever Finn explaining automation to a global dev team over coffee.”


Technically grounded, emotionally aware. Focus on real problems engineers face (messy tools, silos, time wasted) and offer solutions that feel human and empowering.


Occasionally playful, never silly. A touch of dry humor goes far. Think: “The Swiss Army knife of automation,” not “Let’s automate all the things!!!”

Stylistic Touches (Inspired by Visual Identity)
Keep it modular: Reflect the "grid-based" clarity of the visual guidelines by structuring text in clear sections.
Use bullet points or keywords to keep messages concise and organized.
Example: "Test. Automate. Innovate. Robot Framework simplifies it all."
Minimalist wordplay: Reflect the playful yet technical tone of "YES WE'R OPEN SRC" from the visual guidelines.

Avoid These Pitfalls
Jargon or overly explanatory text:
Instead of: "Robot Framework is a general-purpose automation framework..."
Use: "Automation for every need. Robot Framework makes it simple."
Generic corporate tone:
Avoid phrases like "Our mission is to..." and replace them with action-driven statements.

Using "The Robot Framework Voice" as a Prompt
Your idea of using the full "The Robot Framework Voice" framework as a prompt is valid, but here’s the key consideration:
Pros: It ensures consistency and alignment with the brand’s tone across all the pages.
Cons: It might be too verbose or unfocused, especially for generating specific, detailed sections like /process.
Optimized Prompt Approach
Instead of using the entire voice framework verbatim, I suggest breaking it into modular prompts tailored to each page. This ensures specificity while keeping the tone consistent. For example:

For Etusivu:
"Write a homepage section highlighting the new Robot Framework Certification program. Use the Robot Framework voice: friendly, versatile, and effective. Emphasize accessibility, community belonging, and the value of certification in advancing automation expertise. Keep it brief and engaging, with a strong Call-to-Action button linking to the detailed product page."

For /certificates/rf-1:
"Write a detailed product page for the Robot Framework Certification program. Use the Robot Framework voice: professional, approachable, and technically clear. Include sections on the certification's value, levels, how to prepare, and benefits for individuals and teams. Highlight accessibility and connection to the community while avoiding jargon. Include a clear Call-to-Action to register."

For /providers:
"Write a page listing approved certification providers and instructions for becoming a Robot Framework partner. Use the Robot Framework voice: professional yet approachable, emphasizing community collaboration and accessibility. Include a clear Call-to-Action for interested providers."

For /process:
"Write a general instruction page for the Robot Framework Certification process. Use the Robot Framework voice: clear, concise, and accessible. Include steps to register, exam details, how to receive results, and where to get support. Keep the tone professional yet approachable, avoiding unnecessary complexity."
